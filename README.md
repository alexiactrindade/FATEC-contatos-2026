## Descrição

Esta atividade teve como objetivo o desenvolvimento da interface funcional de um sistema de gerenciamento de contatos utilizando JavaScript. O código realiza a integração entre o front-end e uma API REST, permitindo listar, cadastrar, atualizar e excluir contatos dinamicamente. Foram utilizados métodos assíncronos com async/await para comunicação com o servidor. Além disso, a aplicação manipula elementos do DOM para preencher tabelas, atualizar formulários e exibir informações ao usuário. Também foram implementados eventos de clique para ações de salvar, editar, atualizar e excluir registros. O projeto contribuiu para o aprendizado de manipulação de dados, consumo de API e interação dinâmica com páginas web.
